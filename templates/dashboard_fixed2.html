🧠 Distributed LLM Inference

                                            
Workers call their local Ollama instance. Each worker uses its own GPU/RAM to run the model — compute is truly distributed across the cluster.

                                        

                                        

                                            

                                                
                                                
                                                Must be pulled on each worker: ollama pull deepseek-r1:7b
                                            

                                            

                                                
                                                
                                            

                                        

                                        
                                        

                                            

                                                
                                                
                                                Each worker takes a different reasoning path (step-by-step, analytical, multi-perspective, etc.) and returns its own answer. Compare results!
                                            

                                        

                                        
                                        

                                            

                                                
                                                
                                                Workers split the list — each worker answers its own subset of questions in parallel.
                                            

                                        

                                        
                                        

                                            

                                                
                                                
                                                The document is split by character count across workers. Each worker summarises its section, master combines.
                                            

                                        

                                        

                                            
                                            
                                            Workers call Ollama on their own machine at this address. Change only if Ollama runs on a different port.
